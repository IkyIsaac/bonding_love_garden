# User Guide

Bonding Love Garden is a play park management platform with three ways in, depending on who you are:

- **Parents / individual customers** — the mobile app's Customer experience: register, manage your family, buy access plans, view your QR wristbands, track game credits, book reservations.
- **Cashiers, attendants, supervisors** — the same mobile app's Staff experience: register/assist walk-in customers, sell plans, scan QR wristbands, manage active sessions.
- **Owner / manager** — the web admin dashboard: configure everything (games, plans, pricing, discounts, packages, staff) and view reports.

This section covers what's usable today. As the mobile app ships, its guides will land here too — see `PROGRESS.md` in the repo for current build status.
